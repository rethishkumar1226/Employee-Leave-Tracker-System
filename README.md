# Employee Leave Tracking System (React.js, Spring Boot, MySQL)

## 📌 Project Overview

The **Employee Leave Tracking System** is a full-stack web application designed to simplify and automate employee leave management. The system allows employees to submit leave requests, managers to review and approve or reject applications, and administrators to manage employee leave records efficiently.

The application provides a centralized platform for tracking leave details, improving transparency, reducing manual processes, and streamlining leave approval workflows.

## 🚀 Features

- Employee registration and authentication
- Employee profile management
- Apply for leave requests
- View leave history and status
- Manager approval/rejection of leave requests
- Track available leave balance
- Manage employee leave records
- Responsive user interface
- Secure communication between frontend and backend
